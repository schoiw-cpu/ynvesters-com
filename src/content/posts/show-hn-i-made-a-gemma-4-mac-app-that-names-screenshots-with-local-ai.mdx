## What SnapName Actually Does

Before diving into pricing, it helps to understand the technical underpinning, because it directly justifies the cost structure.

SnapName uses [Gemma 4](https://blog.google/technology/developers/google-gemma-4/), Google's open-weight multimodal model, running locally via Apple's [Core ML](https://developer.apple.com/documentation/coreml) and Metal Performance Shaders on Apple Silicon. The model ingests a screenshot image, generates a descriptive label, and renames the file — all without the image leaving your machine. For professionals handling sensitive data (legal documents, financial dashboards, client UI screenshots), that local-only guarantee is not a small thing.

The workflow is intentionally minimal:

- **Watch folder mode** — point SnapName at a folder (typically `~/Desktop` or `~/Downloads`) and it renames new screenshots as they arrive.
- **Batch rename** — select a group of existing screenshots and process them in one pass.
- **Manual trigger** — drag a single file onto the app icon or menu bar widget.

The generated names follow a readable slug format, something like `stripe-dashboard-revenue-chart-q4.png` instead of `Screenshot 2024-11-03 at 2.47.31 PM.png`. You can configure naming conventions (date prefix, lowercase, separator style) in settings.

Because everything runs on-device, performance depends on your hardware. On an M3 MacBook Pro, renaming a single screenshot takes roughly two to four seconds. Batch jobs of 50+ files run sequentially, which means a large backlog can take a few minutes. This is a real limitation compared to cloud-based tools that can parallelize across servers.

## Pricing Tiers Explained

SnapName uses a one-time purchase model with a free tier for evaluation. Here's what the app offers:

### Free Tier

The free version gives you:

- **Up to 20 renames per month** (resets on the calendar month)
- Access to the core watch-folder feature
- Manual drag-and-drop renaming
- No API key or account required

The 20-rename monthly cap is honest about what it is: a trial, not a permanent free plan. For someone who takes screenshots occasionally — say, one or two a day for documentation — 20 renames will run out in the first week of active use. It's enough to validate that the AI naming quality meets your standards before committing money.

### One-Time Purchase (Paid)

SnapName sells lifetime access for a **one-time fee of $19** (pricing as listed on [snapname.app](https://snapname.app) at time of writing; verify current pricing before purchasing).

What the paid version unlocks:

- **Unlimited renames** — no monthly cap
- **Batch processing** — select and rename large groups of screenshots at once
- **Custom naming rules** — configure date formats, slug separators, prefix/suffix patterns
- **Priority support** — direct email support from the developer
- **All future updates** — the app is positioned as a one-time purchase with ongoing updates included

There are no annual fees, no seat limits (it activates on up to two Macs per license per the standard Mac App Store terms), and no usage telemetry sent to a server because there is no server-side component to speak of.

### No Enterprise Tier (Yet)

At the time of writing, SnapName does not offer team licensing, volume discounts, MDM deployment support, or an API. If you're evaluating this for a team of designers or developers all drowning in screenshots, each person would need to purchase individually. The developer has acknowledged this limitation in the [Hacker News thread where SnapName was first shared](https://news.ycombinator.com/), and team/enterprise pricing is on the roadmap but not yet available.

## Comparison: SnapName vs. Alternatives

You have real alternatives here, and each makes a different trade-off across price, privacy, and capability.

| Tool | Price | AI Model | Local/Cloud | Batch Rename | Platform |
|---|---|---|---|---|---|
| **SnapName** | Free / $19 one-time | Gemma 4 (local) | Local only | Yes (paid) | macOS only |
| **Recut / Rename files via Finder** | Free (built-in) | None | N/A | Yes (manual) | macOS |
| **Apple Intelligence (macOS Sequoia+)** | Free (hardware req.) | Apple on-device | Local | Limited | macOS |
| **Namechk AI Rename** | $8/mo | GPT-4o (cloud) | Cloud | Yes | Web / Mac |
| **CleanMyMac X (file tools)** | $39.95/yr | None | N/A | Rule-based | macOS |
| **Hazel + custom AI script** | $42 one-time + API costs | Any (DIY) | Configurable | Yes | macOS |

A few things stand out from this comparison:

**Apple Intelligence** is the obvious first question. macOS Sequoia introduced [Writing Tools and some image understanding features](https://www.apple.com/apple-intelligence/), but Apple's built-in tools do not currently auto-rename screenshots with descriptive AI-generated filenames. They can summarize text and assist in writing apps, but the specific workflow of "watch a folder and rename image files based on visual content" is not something the OS handles natively as of macOS 15. If Apple ships this feature in a future update, the calculus changes — but it hasn't yet.

**Hazel** is the power-user alternative. [Hazel](https://www.noodlesoft.com/) is a mature Mac automation tool that can watch folders and rename files using rules. You could theoretically pipe screenshots through an AI vision API (OpenAI, Anthropic, or a local Ollama instance) via shell script to generate names, then have Hazel apply them. This is genuinely powerful and more flexible than SnapName. But it requires comfort with scripting, API key management, and ongoing per-token costs if you use a cloud model. SnapName charges $19 once and hides all of that complexity.

**Cloud-based AI rename tools** like Namechk AI or similar SaaS products do what SnapName does, but your screenshots travel to a third-party server. For anyone handling NDA-covered designs, financial data, or personal information, that's a non-starter. SnapName's local-only processing is its clearest competitive advantage over this category.

## Is the $19 Price Fair?

Let's do the math from a few angles.

**Versus cloud API costs:** If you take 10 screenshots a day (a modest estimate for a developer or designer), that's roughly 300 screenshots a month. Running those through GPT-4o Vision via API costs approximately $0.01–$0.02 per image depending on resolution, which adds up to $3–$6/month, or $36–$72/year. SnapName's $19 one-time fee pays for itself in under six months compared to a DIY cloud approach — and you don't have the setup overhead.

**Versus subscription software:** The Mac productivity software market is littered with $5–$10/month subscriptions. A single year of a comparable SaaS tool would run $60–$120. $19 once, with all future updates included, is priced conservatively.

**Versus doing nothing:** The hidden cost of manually organizing screenshots is real but diffuse. If you spend 10 minutes a week renaming and searching for screenshots, that's roughly 8+ hours a year. At any professional hourly rate, $19 is a rounding error.

**Versus the free tier:** The 20-rename free cap is enough to evaluate quality but not enough to rely on. If you take even a few screenshots daily for work, you'll hit the limit within the first week. This is by design — SnapName isn't trying to sustain a free tier indefinitely, and the cap makes the upgrade decision simple.

The $19 price feels honest for an indie Mac app from a solo developer. It's not trying to extract subscription revenue from a utility that doesn't need to be a subscription.

## Privacy and Security: Does the Local-Only Claim Hold Up?

For many buyers, this is the real question. SnapName's marketing centers on the fact that your screenshots never leave your Mac. Here's what that means technically:

- **Gemma 4 runs via a local inference runtime** — on Apple Silicon Macs, this is likely via [llama.cpp](https://github.com/ggerganov/llama.cpp), [MLX](https://github.com/ml-explore/mlx), or Apple's own Core ML pipeline. The model weights are downloaded once and stored locally.
- **No account creation required** — the free tier and paid activation don't require signing into a cloud account or syncing data externally.
- **Network requests** — the app does make network requests for license validation on purchase, which is standard for paid Mac apps. The screenshot data itself is not transmitted.

If you want to verify these claims independently, tools like [Little Snitch](https://www.obdev.at/products/littlesnitch/index.html) can monitor outbound connections and confirm whether image data is leaving your machine. This is a reasonable step for anyone handling genuinely sensitive screenshots.

One caveat: the model weights for Gemma 4 multimodal are not small. Expect the app to require several gigabytes of storage for the local model. On machines with limited SSD space, this is worth checking before purchase.

## Who Should Buy SnapName

**Buy it if you:**

- Take 20+ screenshots a month for work and spend time finding or renaming them
- Handle sensitive client data, legal documents, or financial information and can't use cloud tools
- Are a solo designer, developer, or writer who wants a set-it-and-forget-it solution without scripting
- Have an Apple Silicon Mac (M1 or later) and at least 8GB of RAM for reasonable inference speed
- Prefer one-time purchases over subscriptions on principle

**Skip it (for now) if you:**

- Are on an Intel Mac — local AI inference will be slow and the app may not be optimized for Intel
- Need team licensing or centralized management across multiple machines
- Are comfortable with Hazel + a local Ollama setup and want more flexibility
- Take screenshots rarely enough that the free 20-rename tier covers your actual usage
- Need renaming to integrate into a larger automation pipeline (Zapier, n8n, custom scripts) — SnapName doesn't expose hooks for this yet
