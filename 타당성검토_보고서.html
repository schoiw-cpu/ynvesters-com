AdSense 승인 유지 위험 도메인 주제 전환 → 재심사 트리거 가능. 도메인 재구매 상태라 어차피 신규 신청에 가까움.

5자동화 파이프라인 (일간 작업 흐름)

1
토픽 발굴
Product Hunt RSS + Hacker News API + 중복 제거 → 1개 토픽 선정
2
1차 데이터 수집 (anti-slop 핵심)
공식 사이트 스크래핑 · GitHub 메타 · Reddit 실 사용자 후기 3~5개
3
Claude 글 생성
문체 템플릿 10개 중 랜덤 · 1차 데이터 컨텍스트 주입 · 단어 수 1,500~2,200 랜덤
4
이미지 자동화
Unsplash API 1~2장 + 어트리뷰션 자동 삽입
5
품질 게이트
토큰 < 1,200 또는 자체 평가 < 7/10이면 폐기 → 그날 발행 건너뜀 (자연 속도 제한)
6
커밋 + 푸시
git commit → main → Cloudflare Pages 자동 재배포
7
색인 요청
sitemap.xml 갱신 + Google Search Console Indexing API 호출 (선택)
의도적 발행 속도 제한. cron은 일 1회지만 품질 게이트로 자연 reject 유도 + 주말 스킵 → 실제 발행은 주 5건 상한. 처음 30일은 주 3건만 발행해 Scaled Content Abuse 신호를 회피합니다.

위반 신호회피 전략

발행 속도 비정상주 5건 상한 · 주말 스킵 · 품질 게이트 자연 변동
광고 비율 과다1,500자+ 글에만 광고 3개 상한 · 첫 화면 위는 1개만
외부 링크 부재모든 글에 권위 사이트 외부 링크 3+ (위키 · GitHub · 공식 docs)

Plan B — BAN 발생 시

  • 도메인 1개에 자산 집중 금지 → 백업 도메인 1개 추가 등록 ($10/년) 권장
  • 콘텐츠 DB는 GitHub에 매일 백업 → 도메인만 바꿔 즉시 재시작 가능
  • AdSense BAN은 사이트 단위로 시작될 수 있으므로 새 도메인 재신청 경로 유지

8실행 단계

Phase 1 — 인프라 부트스트랩 (1일차)

  • Astro 프로젝트 초기화
  • Cloudflare Pages ↔ GitHub 연동
  • ads.txt, robots.txt, sitemap 설정
  • 도메인 DNS 연결

Phase 2 — 콘텐츠 파이프라인 (1~3일차)

  • discover-topics.mjs
  • generate-post.mjs (배치 API · 10템플릿)
  • fetch-images.mjs
  • orchestrator.mjs (품질 게이트 포함)
  • 로컬 5건 시범 생성 + 수동 검토

Phase 3 — 사이트 외형 (3~4일차)

  • About / Privacy / Contact
  • AdUnit.astro (CLS-safe, lazyOnload)
  • JSON-LD (Article + Author + Org)
  • 다크모드 reading-friendly 디자인

Phase 4 — 자동화 가동 (5일차~)

  • GitHub Actions cron 등록
  • API 키 → GitHub Secrets
  • 첫 7일: 일 1건 · 매일 확인
  • 30일 후 AdSense 광고 활성화

Phase 5 — 모니터링 (지속)

  • Search Console 색인 상태 주간 점검
  • AdSense 정책 알림 주간 점검
  • 90일 시점 토픽 조정

End-to-End 검증

  • orchestrator.mjs --dry-run
  • npm run dev 로컬 렌더링
  • npm run build sitemap/RSS/ads.txt 확인
  • Lighthouse Performance/SEO 90+
  • CLS < 0.1, INP < 200ms

9실행 전 추가 확인 사항

  1. 도메인명 — 재구매할 도메인 확정 후 Phase 1에서 DNS 설정
  2. 의사 저자 프로필 윤리 — 가공 인물 사용 vs "Editorial Team" 단체 명의 대체
  3. AdSense 광고 활성화 시점 — 첫날 vs 30개 글 누적 후 (후자 권장)
  4. 백업 도메인 등록 — BAN 대비 Plan B용 추가 도메인 ($10/년)
  5. 콘텐츠 라이센스 — CC-BY 표기 등 정책
